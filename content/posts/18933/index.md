Just like I also [wrote more than a year ago](https://alper.nl/posts/keeping-claude-in-check-with-jujutsu/), there's a lot to be gained from using jj as the version control harness for your LLM. It removes a lot of the cruft of git and simplifies concepts and flows.

The only downside is that git is so much more widespread that LLMs know how to use it almost by default, but I hope that may finally be changing.

Turns out this is a thought with enough currency to merit writing a book about it. Nice to see somebody jumping on that.
